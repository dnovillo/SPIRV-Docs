DEPRECATION NOTICE

The SPIR Working Group intends to remove this spec generator after the
SPIR-V specification source migrates to GitHub. See SPIR-V issue #940
(https://gitlab.khronos.org/spirv/SPIR-V/-/issues/940). It is kept for now so
the existing spec build continues to work.

This is a disassembler and document generator for SPIR V.

Use CMake to build into the subdirectory "build".

Ensure it installs the executable into "build/install/bin/spirv.exe".
